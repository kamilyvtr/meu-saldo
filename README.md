<h2 id="sobre"><img src="https://api.iconify.design/lucide/info.svg?color=%236366F1" width="24" height="24" align="absmiddle" alt="" /> Sobre o Projeto</h2>

O **Meu Saldo** é uma aplicação PWA (Progressive Web App) desenvolvida para simplificar o controle financeiro pessoal. O sistema permite registrar despesas em poucos toques, gerenciar cartões de crédito sem duplicar despesas (Regra de Ouro), acompanhar metas, orçamentos e visualizar a saúde financeira em dashboards intuitivos.

A segurança e a integridade dos dados financeiros são tratadas como requisitos centrais da arquitetura.

| Princípio | Implementação |
| :--- | :--- |
| <img src="https://api.iconify.design/lucide/coins.svg?color=%236366F1" width="18" height="18" align="absmiddle" alt="" /> **Precisão monetária** | Valores armazenados estritamente como `integer` (centavos), evitando erros de ponto flutuante. |

<h2 id="estrutura"><img src="https://api.iconify.design/lucide/folder-tree.svg?color=%236366F1" width="24" height="24" align="absmiddle" alt="" /> Estrutura do Projeto</h2>

O backend segue o padrão **MVC (Model-View-Controller)** do Laravel, com as regras de negócio isoladas fora dos controllers para manter o código testável e de fácil manutenção.

| Camada | Responsabilidade |
| :--- | :--- |
| <img src="https://api.iconify.design/lucide/database.svg?color=%236366F1" width="18" height="18" align="absmiddle" alt="" /> **Model** | Entidades de domínio e relacionamentos (Eloquent). |
| <img src="https://api.iconify.design/lucide/monitor.svg?color=%236366F1" width="18" height="18" align="absmiddle" alt="" /> **View** | Interface em Vue.js 3 e Tailwind CSS, consumindo os dados do backend. |
| <img src="https://api.iconify.design/lucide/route.svg?color=%236366F1" width="18" height="18" align="absmiddle" alt="" /> **Controller** | Recebe a requisição, delega a lógica e devolve a resposta. Não concentra regras de negócio. |
| <img src="https://api.iconify.design/lucide/lock-keyhole.svg?color=%236366F1" width="18" height="18" align="absmiddle" alt="" /> **Policy** | Regras de autorização e isolamento de dados entre usuários. |
| <img src="https://api.iconify.design/lucide/cog.svg?color=%236366F1" width="18" height="18" align="absmiddle" alt="" /> **Service / Actions** | Regras de negócio: Regra de Ouro dos cartões, classificação automática e recorrências. |

```text
meu-saldo/
├── app/
│   ├── Http/
│   │   ├── Controllers/     # Entrada das requisições (camada fina)
│   │   └── Requests/        # Validação de dados (Form Requests)
│   ├── Models/              # Entidades e relacionamentos (Eloquent)
│   ├── Policies/            # Autorização e isolamento de dados
│   └── Services/            # Regras de negócio da aplicação
├── database/
│   ├── migrations/          # Esquema do banco de dados
│   └── seeders/             # Dados iniciais
├── resources/
│   ├── js/                  # Componentes e páginas Vue 3
│   └── css/                 # Estilos Tailwind CSS
├── routes/                  # Definição de rotas web e API
├── public/                  # Assets públicos, manifest e Service Worker
└── tests/                   # Testes automatizados
```

> A organização acima é ilustrativa. Ajuste os diretórios conforme a estrutura real do repositório.

<h3><img src="https://api.iconify.design/lucide/rocket.svg?color=%236366F1" width="20" height="20" align="absmiddle" alt="" /> Passo a Passo</h3>

**1. Clone o repositório**

```bash
git clone <url-do-repositorio> meu-saldo
cd meu-saldo
```

**2. Instale as dependências do backend**

```bash
composer install
```

**3. Instale as dependências do frontend**

```bash
npm install
```

**4. Configure o ambiente**

```bash
# Cria o arquivo de variáveis de ambiente
cp .env.example .env

# Gera a chave de criptografia da aplicação
php artisan key:generate
```

**5. Prepare o banco de dados**

```bash
# Cria o arquivo do banco SQLite
touch database/database.sqlite

# Executa as migrations e popula os dados iniciais
php artisan migrate --seed
```

**6. Compile os assets e inicie o servidor**

```bash
# Compila os assets de frontend
npm run build

# Inicia o servidor local
php artisan serve
```
